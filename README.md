# DentalClinic

# 🦷 Квио – Система онлайн-записи в стоматологическую клинику

**Квио** – это приложение для автоматизации записи пациентов в стоматологической клинике.  
Проект разработан в рамках дипломной работы и предназначен для удобного взаимодействия между пациентами, врачами и администраторами.

## 📌 Основные возможности

### Для пациентов
– Просмотр услуг и цен  
– Запись на приём к врачу  
– Личный кабинет с историей визитов  
– Редактирование профиля

### Для врачей
– Просмотр записей на текущий день  
– Постановка диагноза и рекомендаций

### Для администраторов
– Управление пользователями (добавление, редактирование, удаление)  
– Управление врачами и услугами  
– Просмотр и изменение записей  
– Статистика клиники

## 🛠 Технологии

– **C#**, **WPF** – клиентская часть  
– **PostgreSQL** – база данных  
– **.NET Framework 4.8**  
– **Npgsql** – подключение к БД  
– **EPPlus** – экспорт в Excel
